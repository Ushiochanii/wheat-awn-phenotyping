Export measurements

Each image is exported as one CSV with two columns: ID and Awn length (mm). Batch export is packaged as ZIP.

Unmeasured values stay blank rather than becoming zero. Results can be exported before manual confirmation.

Detailed export preserves automatic and final lengths, review state, model, and pipeline provenance.
